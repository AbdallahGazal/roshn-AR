# Fix AR Model-Viewer CORS Error

## Problem

In `index.html:8`, the `<script>` tag points to the bare domain `https://googleapis.com` instead of the actual model-viewer library CDN URL. This causes:

1. **CORS error** — `googleapis.com` doesn't serve the model-viewer script and rejects cross-origin requests from `http://127.0.0.1:5500`.
2. **`net::ERR_FAILED`** — The script resource fails to load entirely.
3. **model-viewer not defined** — Since the library never loads, the `<model-viewer>` custom element doesn't work.

## Fix

### Step 1: Update the script `src` URL in `index.html`

**File:** `index.html`, line 8

**Change:**
```html
<script type="module" src="https://googleapis.com"></script>
```

**To:**
```html
<script type="module" src="https://ajax.googleapis.com/ajax/libs/model-viewer/4.2.0/model-viewer.min.js"></script>
```

This is the official Google-hosted CDN URL for model-viewer v4.2.0 (latest stable). It includes proper CORS headers and serves the actual JavaScript library.

### That's it

No other changes are needed. The rest of the HTML (model paths `roshn.glb` / `roshn.usdz`, attributes, styling) is correct. Both model files exist in the project directory.
