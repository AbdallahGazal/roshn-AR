# Fix AR Model-Viewer: CORS Error + Custom AR Button

## Problem 1: CORS / Script Loading Error

In `index.html:8`, the `<script>` tag points to the bare domain `https://googleapis.com` instead of the actual model-viewer library CDN URL. This causes the CORS and `net::ERR_FAILED` errors.

## Problem 2: Default AR Button Too Small

The default model-viewer AR button is a tiny icon in the bottom-right corner. Users don't notice it or know what it does. It needs to be replaced with a large, prominent, branded button that encourages interaction.

---

## Changes (all in `index.html`)

### Step 1: Fix the script URL (line 8)

**Change:**
```html
<script type="module" src="https://googleapis.com"></script>
```

**To:**
```html
<script type="module" src="https://ajax.googleapis.com/ajax/libs/model-viewer/4.2.0/model-viewer.min.js"></script>
```

This is the official Google-hosted CDN URL for model-viewer v4.2.0 (latest stable).

### Step 2: Add a custom AR button using the `ar-button` slot

Model-viewer supports replacing its default AR button by placing an element with `slot="ar-button"` inside the `<model-viewer>` tag. This button is **only visible on AR-capable devices** (phones/tablets).

**Add inside `<model-viewer>`:**
```html
<button slot="ar-button" id="ar-button">
    View in Your Space
</button>
```

### Step 3: Style the custom button

Add CSS to make the button large, centered at the bottom, pill-shaped, with a bold color and subtle animation to draw attention:

```css
#ar-button {
    background-color: #2563EB;
    color: white;
    position: absolute;
    bottom: 24px;
    left: 50%;
    transform: translateX(-50%);
    white-space: nowrap;
    padding: 16px 36px;
    font-family: 'Segoe UI', Roboto, Helvetica Neue, sans-serif;
    font-size: 18px;
    font-weight: 600;
    letter-spacing: 0.5px;
    border-radius: 50px;
    border: none;
    cursor: pointer;
    box-shadow: 0 4px 20px rgba(37, 99, 235, 0.4);
    animation: pulse 2s ease-in-out infinite;
    z-index: 10;
}

#ar-button:active {
    background-color: #1D4ED8;
    transform: translateX(-50%) scale(0.97);
}

@keyframes pulse {
    0%, 100% { box-shadow: 0 4px 20px rgba(37, 99, 235, 0.4); }
    50% { box-shadow: 0 4px 30px rgba(37, 99, 235, 0.7); }
}
```

Key design decisions:
- **Large size** (`padding: 16px 36px`, `font-size: 18px`) — easy to tap on mobile
- **Centered at bottom** — natural position for a CTA on a fullscreen viewer
- **Bold blue** (`#2563EB`) — stands out against the model background
- **Pill shape** (`border-radius: 50px`) — modern, inviting look
- **Pulse animation** — subtle glow animation draws the eye without being distracting
- **Clear text** ("View in Your Space") — tells the user exactly what will happen

### Final `index.html`

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Our Product AR Experience</title>
    <script type="module" src="https://ajax.googleapis.com/ajax/libs/model-viewer/4.2.0/model-viewer.min.js"></script>
    <style>
        body, html { margin: 0; padding: 0; width: 100%; height: 100%; overflow: hidden; background-color: #f7f7f7; }
        model-viewer { width: 100%; height: 100%; }

        #ar-button {
            background-color: #2563EB;
            color: white;
            position: absolute;
            bottom: 24px;
            left: 50%;
            transform: translateX(-50%);
            white-space: nowrap;
            padding: 16px 36px;
            font-family: 'Segoe UI', Roboto, Helvetica Neue, sans-serif;
            font-size: 18px;
            font-weight: 600;
            letter-spacing: 0.5px;
            border-radius: 50px;
            border: none;
            cursor: pointer;
            box-shadow: 0 4px 20px rgba(37, 99, 235, 0.4);
            animation: pulse 2s ease-in-out infinite;
            z-index: 10;
        }

        #ar-button:active {
            background-color: #1D4ED8;
            transform: translateX(-50%) scale(0.97);
        }

        @keyframes pulse {
            0%, 100% { box-shadow: 0 4px 20px rgba(37, 99, 235, 0.4); }
            50% { box-shadow: 0 4px 30px rgba(37, 99, 235, 0.7); }
        }
    </style>
</head>
<body>

    <model-viewer 
        src="roshn.glb" 
        ios-src="roshn.usdz" 
        ar 
        ar-modes="scene-viewer quick-look webxr" 
        camera-controls 
        auto-rotate 
        shadow-intensity="1">

        <button slot="ar-button" id="ar-button">
            View in Your Space
        </button>

    </model-viewer>

</body>
</html>
```

### Notes

- The `slot="ar-button"` element is **only rendered on AR-capable devices**. On desktop browsers, it will be hidden automatically by model-viewer — no additional logic needed.
- Both model files (`roshn.glb`, `roshn.usdz`) already exist in the project directory.
